# 使用方法

## 物品

「训练假人」物品位于独立的创造模式物品栏，最多堆叠 16 个。

- 对方块顶面右键：在其上方放置假人，假人面朝放置者；空间被方块或实体占据时放置失败。非创造模式消耗一个。
- 对假人潜行并空手右键：收回假人，物品进入背包（满时掉落在脚下）。
- 对假人使用鼠标中键选取得到同一物品。

物品图标 `textures/item/dummy.png` 为 CPA 生成（gpt-image-2.5-flare），透明底；物品模型取 `item/generated`，
不限贴图尺寸。原稿与提示词在仓外交接目录 `handoff/humanoid-dummy-art-work/v2/`。

## 命令

根命令 `/meridian_humanoid_dummy`，需要权限等级 2，所有参数都可 Tab 补全。

| 命令 | 作用 |
| --- | --- |
| `spawn [mortal\|wandering\|true]` | 在执行位置生成一个假人，缺省档位取物种表 `default_tier`。反馈「已生成训练假人（档位）：UUID」。 |
| `clear [radius]` | 清除执行位置球形半径内的全部假人；半径 1–256，缺省 16。 |
| `reset <targets>` | 把选中假人的部位、组织与器官回满到出生上限。 |
| `realm <targets> <mortal\|wandering\|true>` | 在原位置、原朝向按新档位重新生成，保留自定义名称，旧假人移除。 |

`targets` 是原版实体选择器，选中的非假人实体被忽略；一个假人都没选中时命令失败。

## 档位

| 参数 | 显示名 | 身体 |
| --- | --- | --- |
| `mortal` | 凡人 | 游炁境界，经脉全部未开 |
| `wandering` | 游炁 | 游炁境界，按物种画像开辟经脉 |
| `true` | 真炁 | 真炁境界 |

## 击打 HUD

只有造成伤害的玩家收到报告，显示在屏幕右上角：最近 3 次命中自上而下叠放，越旧越淡；
最后一次命中 4 秒后整体消失，消失前 0.5 秒渐隐。每次命中一块：

1. 部位、命中后 HP / 上限与本次扣除（打在已归零的部位上时部位本身不扣血，只写 HP）；
2. 伤害类型、护甲前剂量 → 护甲后剂量；
3. 受伤组织与器官（按扣除量降序，最多显示 4 项，其余折叠为计数），蔓延到其他部位的标「蔓延」；
4. 部位从可用变为失能（或反向）时追加高亮行。

HP 保留一位小数；扣减与剂量不小于 0.1 时保留一位，0.01–0.1 保留两位；不足 0.005 的扣减不列出。
模板文案在本模组语言文件里（简体中文与英文）。部位、组织、器官名取 Human 身体数据里的中文显示名，
英文客户端下也显示中文。伤害类型名引用 Damage 的公开键 `damage_kind.meridian.<kind>`，本模组不另写。
