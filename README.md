# Kizuna 经脉训练假人

Minecraft 26.2 Fabric 附属：玩家尺寸的灰色训练假人，身体由 Vanilla-Humanoid-Threatening 按 Human 成人模板真实生成，
伤害全部经 Vanilla-Damage 与 Framework 结算。假人不会死亡，部位可以停在 0 HP；攻击者右上角显示每次命中的部位、剂量与受伤组织。

使用方法、命令、击打报告协议与验证记录统一维护在 [Wiki](docs/wiki/Home.md)。
